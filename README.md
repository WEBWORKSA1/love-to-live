# ♥ LoveToLive.com

**Find where you'll love to live — then live well there.**

A fast, static relocation and quality-of-life platform. It has city rankings and report cards, free calculators, a City Match quiz, a multi-step lead engine, AdSense and YouTube monetization, donations, contests and hiring. It is built to run free on GitHub Pages.

**Live site:** https://webworksa1.github.io/love-to-live/

## How it's built (free GitHub Pages, no build step)

This repo is a **Jekyll site that GitHub Pages builds automatically**, so there are no Actions and no dependencies.

- `_layouts/default.html`: the shared header, footer, cookie banner, sticky CTA, lead-magnet modal and SEO tags.
- `_layouts/city.html`: renders every `places/<city>.html` report card from `_data/cities.json`.
- `_layouts/guide.html`: the guide template (table of contents, related guides, lead module).
- `_includes/`: city card, city dropdown options, breadcrumbs (+ JSON-LD), ad slot, lead module.
- `data/cities.json`, `sitemap.xml` and `robots.txt` are generated by Liquid at build time.

**Publish:** go to **Settings → Pages → Build and deployment → Deploy from a branch**, choose `main` and `/ (root)`, then save. The site goes live at https://webworksa1.github.io/love-to-live/ within about a minute.

## Go-live checklist (edit `assets/js/config.js` only)

1. **Forms/leads:** create a free endpoint at [Formspree](https://formspree.io) or [Web3Forms](https://web3forms.com), or use a Google Apps Script that writes to Sheets. Paste it into `forms.leads` and `forms.default`. Until then, submissions are only saved in the visitor's own browser, and you will not receive them.
2. **AdSense:** once approved, set `adsense.client` and the slot IDs, and put your line in `/ads.txt`.
3. **Donations:** add Stripe Payment Links, PayPal, Ko-fi, Buy Me a Coffee, GitHub Sponsors and/or Patreon URLs. Unused buttons hide themselves.
4. **YouTube:** set `channelUrl`/`channelId`, `featured` video IDs and `cityVideos`.
5. **Social, GA4 and partner affiliate URLs:** optional.

## Custom domain (LoveToLive.com)

1. Go to **Settings → Pages → Custom domain**, enter `lovetolive.com` and save.
2. At your registrar, add A records for `@` pointing to `185.199.108.153`, `185.199.109.153`, `185.199.110.153` and `185.199.111.153`, plus a CNAME record for `www` pointing to `webworksa1.github.io`.
3. In `_config.yml`, set `site_url: https://lovetolive.com` and `baseurl: ""`. That updates canonicals, JSON-LD and the sitemap.
4. Enable **Enforce HTTPS**, and submit `https://lovetolive.com/sitemap.xml` to Google Search Console.

## Editing content

- **Pages:** edit the `.html` files directly. Everything below the front matter is page content.
- **Cities:** each city is one object in `_data/cities.json` plus a stub in `places/`. Scores are 0–100, and `g` holds the letter grades.
- **Guides:** `guides/*.html`. Headings listed in the front-matter `toc` appear in the sidebar.
